# Documentação e imagens

O arquivo `dashboard-placeholder.svg` é apenas um espaço reservado para a foto do dashboard. Substitua-o pela captura de tela que deseja exibir ou atualize o link da imagem no README principal.

Antes de adicionar uma captura, oculte nomes de fornecedores, valores, vencimentos e quaisquer outros dados financeiros ou pessoais reais. Prefira dados fictícios.
