# Documentação e imagens

O README principal exibe as duas capturas originais fornecidas: `dashboard-original.jpeg` e `dashboard-detalhe.png`. `dashboard.png` é a versão anonimizada criada anteriormente.

Antes de adicionar uma captura, oculte nomes de fornecedores, valores, vencimentos, documentos e quaisquer outros dados financeiros ou pessoais reais. Prefira dados fictícios.

Antes de publicar novas capturas sem anonimização, confira se os dados financeiros e pessoais visíveis podem ser divulgados. Se precisar, use a cópia anonimizada como referência.

A especificação detalhada, as decisões técnicas e as limitações conhecidas da implementação estão em [`implementation-notes.md`](implementation-notes.md).
